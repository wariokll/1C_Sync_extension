Пакет подбора документов для типовой синхронизации 1С
=====================================================

1. Распакуйте архив и скопируйте всю папку «ПакетПодбораДокументовДляСинхронизации»
   на удалённую машину. Сохраните вложенную папку Forms и все файлы в корне пакета.
2. Установите на удалённой машине платформу 1С версии 8.3.27.2214.
3. Откройте PowerShell в папке пакета.
4. Запустите сборку:

   .\СобратьПодборДокументов.ps1

Скрипт ищет 1cv8.exe версии 8.3.27.2214 в стандартных каталогах Program Files.
Если платформа установлена в другом месте, укажите путь явно:

   .\СобратьПодборДокументов.ps1 -DesignerPath 'D:\1C\8.3.27.2214\bin\1cv8.exe'

Перед сборкой можно проверить XML и обработчики без запуска Designer:

   .\СобратьПодборДокументов.ps1 -ValidateOnly

Результат сборки:

   .\output\ПодборДокументовДляСинхронизации.epf

Самостоятельный запуск из файла:
1. Откройте полученный EPF в 1С.
2. Нажмите «Обновить список узлов обмена».
3. В таблице отображаются узлы плана «СинхронизацияДанныхЧерезУниверсальныйФормат», включая текущий.
   Текущий узел можно видеть и использовать для просмотра состава, но передавать документы
   можно только узлу второй базы. Если отображается только текущий, узел-получатель не найден.
4. Нажмите «Загрузить виды документов». Появятся выбранные для обработки документы
   и 14 справочников. Справочники отображаются в списке, даже если пока не входят
   в состав узла; чтобы передавать их, включите их в состав плана обмена.
5. Для поиска документов выберите период и склад из выпадающего списка (или
   «Все склады»), отметьте виды и нажмите «Найти». Отмеченные справочники ищутся
   без фильтра по периоду; их можно искать даже при незаполненных датах.
   Список складов подгружается из справочника «Склады».
6. Лимиты задаются над списками: максимум документов одного вида и максимум
   элементов одного справочника. Значение 0 отключает соответствующий лимит.
   При создании формы установлены прежние значения: 500 и 5000.
7. Над списком видов, найденными объектами и корзиной есть команды «Отметить все»
   и «Снять все» для соответствующего списка. Отметьте нужные найденные документы
   и нажмите «Добавить отмеченные в корзину».
   Новый поиск очищает результаты, но сохраняет корзину.
8. После набора корзины нажмите «Передать в типовой обмен», затем запустите штатную
   синхронизацию выбранного узла-получателя обычным способом.

Разметка формы:
- сверху рядом расположены «Узел связи» и «Параметры отбора»;
- ниже в три колонки идут «Типы документов», «Найденные документы» и «Корзина»;
- таблицы и основные области растягиваются вместе с окном; если ширины не хватает,
  используйте горизонтальную прокрутку таблицы.
- в списках документов отображается строка «Склад*ТипДокумента_ГГГГ-ММ-ДД»; ссылка
  документа остаётся служебным значением и скрыта от пользователя.

Если обработку открывают из другой формы и передают параметр «УзелДляОбмена», список
типов загружается автоматически. В любом случае команда «Загрузить виды документов»
позволяет повторно загрузить состав выбранного узла.

Содержимое пакета:
- New-EpfFromDefinition.ps1 — генератор EPF.
- epf-template.json, ПодборДокументовДляСинхронизации.xml и Forms — минимальные файлы шаблона генератора.
- ОпределениеФормы.json и МодульПодбораДокументов.bsl — определение и код обработки.
- СобратьПодборДокументов.ps1 — скрипт запуска сборки.
